# Circular Linked List Demo

En este proyecto se trabajó con la librería Manim para entender mejor el funcionamiento de las listas circularmente enlazadas y desarrollar un video respecto a ello.

> [!NOTE]
> Se utilizó como referencia la galería de ejemplos de Manim Comunity Edition.

[Librería de ejemplos de Manim](https://github.com/ManimCommunity/manim/tree/main/example_scenes)

### **Software Requerido**
- [Python 3.14.5](https://www.python.org/downloads/release/python-3145/)
- [Manim Comunity Edition](https://docs.manim.community/en/stable/installation.html)

### **Compilación y ejecución del programa**
1. Descargar la carpeta [demo_](demo_) y abrirla en su editor de código de preferencia.
2. En una línea de comandos, navegue a la carpeta [demo_](demo_) y ejecute el siguiente comando:
   `manim -pql demo.py CircularLinkedListDemo`

> El video del demo se reproducirá automáticamente, pero también lo podrá encontrar en la ruta:
> `demo_/media/videos/demo/480p15/CircularLinkedListDemo.mp4`

### **Listas Circulares Enlazadas**
Las listas circularmente enlazadas son una estructura de datos que consiste de nodos. Estos nodos contienen un dato y una referencia al nodo siguiente (lista circular enlazada simple), y una referencia al nodo anterior (lista circular enlazada doble).
La característica principal de las listas enlazadas circulares es que todos sus nodos apuntan siempre a un nodo válido, de esta forma se evita tratar con los punteros nulos.
